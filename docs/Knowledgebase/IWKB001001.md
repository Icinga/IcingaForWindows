# Icinga Knowledgebase - IWKB001001

## Short Message

```text
[UNKNOWN] Unknown parameter "<ParameterName>" supplied via "ifw_api_arguments" for Icinga for Windows Check "<CommandName>" (IWKB001001)
```

---

## Cause

An Icinga `CheckCommand` using the `ifw-api` template passed a non-empty value in `macros.ifw_api_arguments` for a parameter name that **does not exist** on the target `Invoke-IcingaCheck*` PowerShell plugin installed on the agent.

Common reasons include:

1. **Outdated CheckCommand / Director Basket:** The `CheckCommand` definition on the Icinga 2 master or in Icinga Director references a legacy or renamed parameter from an older plugin version, and a non-empty value was configured for that parameter on the Host or Service. *(Note: Optional parameters defined in a `CheckCommand` template whose underlying macro is unset, `null`, or an empty string `""` are automatically ignored and do **not** trigger `IWKB001001`.)*
2. **Typo in a Custom `CheckCommand` Definition:** An argument key inside `arguments = { "-TypoParam" = ... }` does not match any parameter or parameter alias of the PowerShell check function.

---

## Solution

1. **Verify the supported parameters on the Windows host:**
   Run `Get-Help` or inspect `(Get-Command Invoke-IcingaCheck<Name>).Parameters.Keys` in PowerShell on the monitored system, or check the generated API reference in `docs/Icinga.Plugins.Checks.md`.
2. **Update the `CheckCommand` definition or Director Basket:**
   - Remove or rename the obsolete argument entry in your Icinga 2 `CheckCommand` definition or Icinga Director Command arguments tab.
   - Remove the corresponding obsolete custom variable from the Host or Service object if it is no longer used.
   - Redeploy your Icinga 2 / Icinga Director configuration.
